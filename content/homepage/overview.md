## Editorial & Data Principles

WorldElection separates **raw structured JSON datasets** (dates, electoral formulas, precinct counts, party hex overrides, turnout) from **Markdown editorial documents** (SEO metadata, electoral system explainers, FAQs, and methodology notes).

- **Static-First Speed:** Reference guides, country hubs, and completed historical results are statically generated for instant global delivery.
- **Live Night Elasticity:** Active election windows switch seamlessly to incremental revalidation paired with lightweight client-side telemetry polling.
- **Tabular Precision:** All vote counts, margins, and percentages render with tabular lining numerals so figures align vertically without horizontal layout shift as totals update.
